Free for Windows and Android

On Windows and rather not install anything? Get the portable zip, unzip it somewhere like Documents and run WizardSurvivors.exe.

On Windows

  1. Run WizardSurvivors-Setup.exe. It installs in a few seconds, with no admin password needed.
  2. Start Wizard Survivors from the desktop shortcut or the Start menu.
  3. Move with the keyboard or a controller. Your spells cast themselves, so focus on staying alive.

Windows might say "Windows protected your PC". That's because this game isn't from a big company. Click More info, then Run anyway.

It keeps itself up to date. Each time it starts, it checks for new spells and fixes and installs them by itself.

On an Android phone

  1. On the phone, open this page and tap Download for Android.
  2. When it has downloaded, tap WizardSurvivors-android.apk to open it.
  3. Android asks whether your browser may install apps. Tap Settings, turn on Allow from this source, go back, and tap Install.
  4. Open Wizard Survivors from the home screen. Put your thumb anywhere on the screen and drag to move.

It isn't on the Play Store yet, so Android might say it doesn't recognise the app. Tap More details, then Install anyway.

Updates: when a new version is out, the game tells you on its title screen. Tap Download there and install it over the top - your progress stays.
